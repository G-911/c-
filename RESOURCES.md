# Recursos: POO en C++ y estructuras de datos

## Conocimiento

- [LearnCpp.com — Introduction to pointers](https://www.learncpp.com/cpp-tutorial/introduction-to-pointers/)
  El mejor tutorial gratuito de C++ moderno (en inglés). Usar para: `&`, `*`, qué guarda un apuntador.
- [LearnCpp.com — Null pointers](https://www.learncpp.com/cpp-tutorial/null-pointers/)
  Usar para: `nullptr` y por qué desreferenciarlo es un error.
- [LearnCpp.com — Dynamic memory allocation with new and delete](https://www.learncpp.com/cpp-tutorial/dynamic-memory-allocation-with-new-and-delete/)
  Usar para: memoria dinámica, fugas de memoria, apuntadores colgantes.
- [LearnCpp.com — Introduction to object-oriented programming](https://www.learncpp.com/cpp-tutorial/introduction-to-object-oriented-programming/)
  y [Introduction to classes](https://www.learncpp.com/cpp-tutorial/introduction-to-classes/)
  Usar para: qué es un objeto, `class`, `public`/`private`.
- [LearnCpp.com — Constructors](https://www.learncpp.com/cpp-tutorial/introduction-to-constructors/)
  y [Destructors](https://www.learncpp.com/cpp-tutorial/introduction-to-destructors/)
  Usar para: crear y limpiar objetos (clave para liberar los nodos).
- [LearnCpp.com — The hidden this pointer](https://www.learncpp.com/cpp-tutorial/the-hidden-this-pointer-and-member-function-chaining/)
  Usar para: `this`.
- [Stanford CS106B — Linked Lists 1](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/linked-lists1)
  Clase universitaria: nodos, recorrido, y pila y cola hechas con lista enlazada, con constructor y destructor.
  Usar para: lecciones 4–7.
