# Recursos: POO en C++ y estructuras de datos

## Conocimiento

- [LearnCpp.com — Introduction to pointers](https://www.learncpp.com/cpp-tutorial/introduction-to-pointers/)
  El mejor tutorial gratuito de C++ moderno (en inglés). Usar para: `&`, `*`, qué guarda un apuntador.
- [LearnCpp.com — Null pointers](https://www.learncpp.com/cpp-tutorial/null-pointers/)
  Usar para: `nullptr` y por qué desreferenciarlo es un error.
- [LearnCpp.com — Dynamic memory allocation with new and delete](https://www.learncpp.com/cpp-tutorial/dynamic-memory-allocation-with-new-and-delete/)
  Usar para: memoria dinámica, fugas de memoria, apuntadores colgantes.
- [LearnCpp.com — Introduction to object-oriented programming](https://www.learncpp.com/cpp-tutorial/introduction-to-object-oriented-programming/)
  y [Introduction to classes](https://www.learncpp.com/cpp-tutorial/introduction-to-classes/)
  Usar para: qué es un objeto, `class`, `public`/`private`.
- [LearnCpp.com — Constructors](https://www.learncpp.com/cpp-tutorial/introduction-to-constructors/)
  y [Destructors](https://www.learncpp.com/cpp-tutorial/introduction-to-destructors/)
  Usar para: crear y limpiar objetos (clave para liberar los nodos).
- [LearnCpp.com — The hidden this pointer](https://www.learncpp.com/cpp-tutorial/the-hidden-this-pointer-and-member-function-chaining/)
  Usar para: `this`.
- [Stanford CS106B — Linked Lists 1](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/linked-lists1)
  Clase universitaria: nodos, recorrido, y pila y cola hechas con lista enlazada, con constructor y destructor.
  Usar para: lecciones 4–7.

### Nivel 5 · Estructuras de datos II
- [Stanford CS106B — Trees](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/trees/) y [Binary Search Trees](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/binary-search-trees/)
  Clases universitarias con código C++. Usar para: árboles, BST y balanceo (5.1-5.3).
- [Visualizaciones de David Galles (USFCA)](https://www.cs.usfca.edu/~galles/visualization/AVLtree.html)
  Animaciones paso a paso de BST y AVL. Usar para: ver las rotaciones.
- [VisuAlgo](https://visualgo.net/es/sorting) (también [heap](https://visualgo.net/es/heap), [grafos](https://visualgo.net/en/dfsbfs), [hash](https://visualgo.net/en/hashtable))
  Animaciones de algoritmos; interfaz solo en parte en español. Usar para: montículos, ordenamiento, BFS/DFS (5.4-5.7).
- [LearnCpp — Sorting an array using selection sort](https://www.learncpp.com/cpp-tutorial/sorting-an-array-using-selection-sort/)
  Usar para: ordenamiento básico (5.5).
- [Stanford CS106B — Hashing](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/hashing/), [Graphs](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/graphs/) y [Dijkstra](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1206/lectures/dijkstra/)
  Usar para: tablas hash y grafos (5.6-5.7). LearnCpp no tiene capítulos de esto.

### Nivel 6 · Avanzado
- [cppreference — Concurrency support](https://en.cppreference.com/w/cpp/thread)
  Usar para: hilos, mutex, atomic, condition_variable, async (6.1-6.2). LearnCpp no tiene capítulo de hilos.
- [Anthony Williams — *C++ Concurrency in Action*, 2.ª ed.](https://www.manning.com/books/c-plus-plus-concurrency-in-action-second-edition)
  El libro de referencia de concurrencia en C++ (de pago). Usar para: profundizar en el Nivel 6.1-6.2.
- [cppreference — Reference (colapso y referencias de reenvío)](https://en.cppreference.com/w/cpp/language/reference) y [Constraints and concepts](https://en.cppreference.com/w/cpp/language/constraints)
  Usar para: reenvío perfecto y concepts (6.3-6.4).
- [LearnCpp — std::optional](https://www.learncpp.com/cpp-tutorial/stdoptional/), [std::string_view](https://www.learncpp.com/cpp-tutorial/introduction-to-stdstring_view/) y [noexcept](https://www.learncpp.com/cpp-tutorial/exception-specifications-and-noexcept/)
  Usar para: biblioteca moderna y garantías ante errores (6.5-6.6).
- [Refactoring.Guru — Patrones de diseño](https://refactoring.guru/es/design-patterns) (en español)
  Usar para: estrategia, observador, fábrica (6.7).
- [cppreference — Undefined behavior](https://en.cppreference.com/w/cpp/language/ub) y [John Regehr — A Guide to Undefined Behavior in C and C++](https://blog.regehr.org/archives/213)
  Usar para: comportamiento indefinido (6.8).
- [Ulrich Drepper — What every programmer should know about memory](https://lwn.net/Articles/250967/)
  Usar para: la caché y el rendimiento (6.8, mapa de la memoria #cache).
- [LearnCpp — Introduction to testing your code](https://www.learncpp.com/cpp-tutorial/introduction-to-testing-your-code/), [manual de GDB](https://sourceware.org/gdb/current/onlinedocs/gdb.html/) y [GoogleTest con CMake](https://google.github.io/googletest/quickstart-cmake.html)
  Usar para: pruebas y depuración (6.9).
