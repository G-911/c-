Bucles

Repetir sin copiar y pegar: while, do-while y for. ~35 minutos.

Al terminar podrás: escribir un bucle que repite una tarea el número exacto de veces, elegir entre while, do-while y for, y cortarlo a tiempo con break.

Calentamiento (2 minutos): antes de empezar, repite sin mirar el quiz de la lección 1.4 · Condicionales. Todo bucle lleva una condición dentro: si los if están frescos, esto sale solo.

Por qué importa. Recorrer un arreglo, buscar en una lista enlazada, vaciar una pila: todo eso es un bucle. En el Nivel 3 vas a escribir mil veces while (actual != nullptr). Aquí aprendes la mecánica con números, que es lo más fácil de comprobar.

1. while: repite mientras la condición sea verdadera

Pregunta la condición. Si es verdadera, ejecuta el cuerpo y vuelve a preguntar. Si es falsa, sigue con lo que hay después.

int i = 1;
while (i <= 3) {          // ¿i <= 3? sí → entra
    cout << i << " ";
    i++;                   // sin esta línea, i vale 1 para siempre
}
// Muestra: 1 2 3

Cada vuelta se llama iteración. Si la condición es falsa desde el principio, el cuerpo no se ejecuta ni una vez.

2. do-while: primero hace, luego pregunta

Igual que while, pero la condición va al final. Por eso el cuerpo se ejecuta al menos una vez. Es perfecto para menús: siempre quieres mostrar el menú la primera vez.

int opcion;
do {
    cout << "1) Jugar  2) Salir: ";
    cin >> opcion;
} while (opcion != 2);     // ojo: lleva ; al final

3. for: cuando sabes cuántas vueltas

Junta en una línea las tres partes que tenía el while:

for (int i = 1; i <= 3; i++) {
//   ^inicio    ^condición ^paso (al final de cada vuelta)
    cout << i << " ";
}
// Muestra: 1 2 3   — exactamente lo mismo que el while de arriba

El orden es: inicio (una sola vez) → condición → cuerpo → paso → condición → cuerpo… La variable i solo existe dentro del for.

Para contar hacia atrás o de dos en dos, cambia el paso:

for (int i = 10; i > 0; i -= 2) cout << i << " ";   // 10 8 6 4 2

Costumbre que te ahorrará errores: para repetir algo n veces, escribe for (int i = 0; i < n; i++): empieza en 0 y usa <. Es la forma en que se recorren los arreglos (lección 1.7), así que conviene que te salga sola.

4. break y continue

  • break sale del bucle ya, aunque la condición siga siendo verdadera.
  • continue se salta el resto de esta vuelta y pasa a la siguiente.
// Primer múltiplo de 7 mayor que 50
for (int n = 51; ; n++) {          // sin condición: lo corta el break
    if (n % 7 == 0) {
        cout << n;                   // 56
        break;
    }
}

// Solo los impares del 1 al 9
for (int i = 1; i <= 9; i++) {
    if (i % 2 == 0) continue;      // los pares se saltan el cout
    cout << i << " ";              // 1 3 5 7 9
}

5. Bucles anidados

Un bucle dentro de otro. Por cada vuelta del de fuera, el de dentro da todas las suyas. Piensa en filas y columnas:

for (int fila = 1; fila <= 3; fila++) {
    for (int col = 1; col <= 4; col++) {
        cout << "*";
    }
    cout << "\n";                 // al terminar cada fila, salto de línea
}
// ****
// ****
// ****      3 filas × 4 columnas = 12 asteriscos

Si el de dentro usa la variable del de fuera (col <= fila), cada fila mide distinto. Así sale el triángulo del miniproyecto.

6. El bucle infinito

Si la condición nunca se vuelve falsa, el bucle no termina. A veces es a propósito (while (true) con un break dentro). Casi siempre es un error. Si tu programa se queda colgado, páralo en la terminal con Ctrl + C.

Los tres errores que cuelgan o estropean un bucle:

1. Olvidar el paso. while (i < 5) { cout << i; } sin i++: infinito.

2. Un ; de más. for (int i = 0; i < 3; i++); — ese ; es un cuerpo vacío. El bloque { } que viene después se ejecuta una sola vez. Lo mismo con while (...);, que además suele colgarse.

3. Uno de más o de menos. <= en vez de < da una vuelta extra. Comprueba siempre a mano la primera y la última vuelta.

¿Qué pasa en la memoria?

La variable del for se crea una sola vez, en el inicio, y vive mientras dura todo el bucle: por eso i recuerda su valor de una vuelta a otra. Al terminar el bucle, muere. En cambio, una variable declarada dentro del cuerpo nace y muere en cada vuelta. En el rectángulo de asteriscos, col está dentro del cuerpo del for de las filas: se crea de nuevo, valiendo 1, para cada fila.

marco de main

1 → 2 → 3
una caja para todo el bucle

1 → 4, y otra vez desde 1

De ahí sale una regla práctica para el miniproyecto: el acumulador de sumaHasta va antes del bucle. Si lo declaras dentro del cuerpo, renace en 0 en cada vuelta. (Normalmente el compilador reutiliza el mismo hueco del marco en cada vuelta, pero para ti es una caja nueva.)

Miniproyecto 1.5 · cinco bucles clásicos

Abre ejercicios/05-bucles.cpp. Tiene cinco funciones vacías y unas pruebas que se corrigen solas. Escribe solo dentro de las llaves de cada una; qué es exactamente una función lo verás en la lección 1.6.

  1. sumaHasta(n): 1 + 2 + … + n. Un for y un acumulador.
  2. factorial(n): 1 × 2 × … × n. Ojo: el acumulador empieza en 1.
  3. contarDigitos(n): cuántas cifras tiene. Un do-while resuelve el 0.
  4. esPrimo(n): busca divisores y corta con break al encontrar uno.
  5. triangulo(n): bucles anidados que arman "*\n**\n***\n".

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 05-bucles.cpp -o prog && ./prog

Al principio verás varias ✗. Terminaste cuando salgan todas en ✓. Unos 20 minutos.

Si te atascas: haz una tabla en papel con una columna por variable (i, suma…) y una fila por vuelta. Rellénala para n = 3. Casi siempre el fallo está en la primera o en la última vuelta. Si el programa se queda colgado, Ctrl + C y busca qué variable no cambia.

La solución está en soluciones/05-bucles.cpp; ábrela solo después de intentarlo de verdad.
