Arreglos y strings

Muchos datos bajo un solo nombre, y el texto como una fila de letras. ~40 minutos.

Al terminar podrás: crear y recorrer un arreglo, pasarlo a una función junto con su tamaño, y trabajar con texto usando size, [], +, substr, find y getline.

Calentamiento (2 minutos): antes de empezar, repite sin mirar el quiz de la lección 1.6 · Funciones. Si fallas la de la copia (sumarUno), vuelve a leer su punto 6: hoy aparece una excepción.

Por qué importa. El arreglo es la estructura de datos más simple y la vara con la que se miden las demás. En el Nivel 3 compararás la lista enlazada con el arreglo una y otra vez: «insertar al inicio en un arreglo obliga a mover todo; en una lista, no». Para entender esa frase hay que haber recorrido arreglos a mano.

1. Un arreglo: cajas seguidas con un solo nombre

int notas[5] = {7, 9, 6, 10, 8};   // 5 enteros, uno detrás de otro
cout << notas[0];                    // 7  — el PRIMERO es el 0
cout << notas[4];                    // 8  — el ÚLTIMO es el 4 (tamaño − 1)
notas[2] = 10;                       // se lee y se escribe con [ ]
notas[0]
7
notas[1]
9
notas[2]
10
notas[3]
10
notas[4]
8

El número entre corchetes es el índice: cuántos pasos hay desde el principio. Por eso el primero es el 0. El tamaño es fijo: se decide al escribir el programa y no crece.

2. Recorrer: el for de siempre

const int N = 5;
int notas[N] = {7, 9, 6, 10, 8};

int suma = 0;
for (int i = 0; i < N; i++) {    // i = 0, 1, 2, 3, 4
    suma += notas[i];
}
cout << suma / static_cast<double>(N);   // 8 — el promedio

Guarda el tamaño en una constante (const int N) y úsala en todas partes. Si mañana son 6 notas, cambias un solo número.

Salirse del arreglo no da error: da basura. notas[5] en un arreglo de 5 no existe, pero C++ no lo comprueba: lee o escribe la memoria de al lado. El programa puede mostrar un número raro, estropear otra variable o caerse más tarde. Se llama comportamiento indefinido.

El culpable casi siempre es i <= N en vez de i < N. En la lección 1.8 verás at(), que sí avisa.

3. Pasar un arreglo a una función

Un arreglo no sabe su tamaño cuando llega a una función. Por eso se pasa siempre con un segundo parámetro, el tamaño:

int sumar(int arr[], int n) {     // arr[] sin número; n dice cuántos hay
    int s = 0;
    for (int i = 0; i < n; i++) s += arr[i];
    return s;
}

int datos[4] = {1, 2, 3, 4};
cout << sumar(datos, 4);          // 10 — se pasa el nombre, sin [ ]

La excepción a la regla de la copia. En la lección 1.6 viste que una función recibe una copia. Con los arreglos no: la función trabaja sobre el arreglo original, y si lo cambia, el cambio se queda.

void ponerACero(int arr[], int n) {
    for (int i = 0; i < n; i++) arr[i] = 0;
}

int v[3] = {4, 5, 6};
ponerACero(v, 3);
cout << v[0];        // 0 — sí cambió

El porqué (la función recibe la dirección del primer elemento) lo entenderás de golpe en la lección 2.2 · Apuntadores.

4. std::string: texto que sabe su tamaño

Un string es una fila de caracteres (char), como un arreglo, pero mucho más cómodo: sabe su tamaño, crece solo y trae herramientas. Necesita #include <string>.

string s = "pila";
cout << s.size();          // 4      — cuántos caracteres
cout << s[0];              // p      — un char, igual que en un arreglo
s[0] = 'P';                // "Pila" — los char van con comillas simples
string t = s + " y cola";  // "Pila y cola" — + une textos
s += "s";                  // "Pilas"
if (s == "Pilas") { }      // == compara el texto entero

for (size_t i = 0; i < s.size(); i++) {   // recorrer letra a letra
    cout << s[i] << "-";                  // P-i-l-a-s-
}

size() devuelve un número sin signo (size_t). Si comparas con un int, -Wall avisa. Usa size_t i como arriba, o guarda int n = static_cast<int>(s.size());.

5. Cortar y buscar: substr y find

string s = "hola mundo";
//          0123456789
cout << s.substr(5, 3);     // "mun"   — desde la posición 5, 3 caracteres
cout << s.substr(5);        // "mundo" — desde la 5 hasta el final
cout << s.find("mu");       // 5       — dónde empieza

if (s.find("z") == string::npos) {   // npos = "no lo encontré"
    cout << "no hay z";
}

find no devuelve −1 cuando no encuentra: devuelve el valor especial string::npos. Compara siempre con él.

6. Leer una línea entera: getline

cin >> s lee solo hasta el primer espacio. Para leer un nombre completo, usa getline:

string nombre;
cout << "Nombre completo: ";
getline(cin, nombre);        // "Ana María López" entero

El getline que «se salta»: si antes hiciste cin >> edad;, el Enter que pulsaste se queda esperando, y el getline siguiente lo lee como una línea vacía. Arreglo: pon cin.ignore(); entre los dos.

cin >> edad;
cin.ignore();                // se come el Enter que quedó
getline(cin, nombre);

¿Qué pasa en la memoria?

Las 5 cajas de notas están pegadas, en orden, dentro del marco de main. Con direcciones inventadas y un int de 4 bytes (lo normal), quedaría así:

notas[0]
7
0x100
notas[1]
9
0x104
notas[2]
10
0x108
notas[3]
10
0x10C
notas[4]
8
0x110
«notas[5]»
¿?
0x114: memoria ajena

notas[i] es «la dirección del primero + i cajas». Nadie comprueba el límite, así que notas[5] cae en memoria que no es del arreglo. Al llamar ponerACero(v, 3) no se copian las cajas: la función recibe solo la dirección de v[0] y escribe en las originales.

Un string es distinto: en el marco hay un objeto pequeño, y las letras, normalmente, van en otra zona, el montón (heap), donde pueden crecer. Muchas bibliotecas guardan los textos cortos como "pila" dentro del propio objeto. En los dos casos el string se encarga solo de esa memoria.

Miniproyecto 1.7 · tres de arreglos, tres de texto

Abre ejercicios/07-arreglos-y-strings.cpp.

  1. sumaArreglo(arr, n): el recorrido básico.
  2. indiceDe(arr, n, buscado): búsqueda lineal; devuelve −1 si no está.
  3. invertir(arr, n): da la vuelta al arreglo en su sitio (el cambio se queda).
  4. contarVocales(texto): recorrer un string letra a letra.
  5. esPalindromo(texto): «reconocer» se lee igual al revés.
  6. primeraPalabra(frase): find + substr.

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 07-arreglos-y-strings.cpp -o prog && ./prog

Al principio verás varias ✗. Terminaste cuando salgan todas en ✓. Unos 20 minutos.

Si te atascas: dibuja las cajas del arreglo con sus índices, como en el diagrama de arriba, y marca con dos dedos las posiciones i y n - 1 - i. invertir y esPalindromo son el mismo movimiento: los dedos se acercan hasta encontrarse en la mitad.

La solución está en soluciones/07-arreglos-y-strings.cpp; ábrela solo después de intentarlo de verdad.
