Operadores

Hacer cuentas y preguntas. Y la división que no da lo que esperas. ~30 minutos.

Calentamiento (3 minutos). Antes de empezar, repite sin mirar el quiz de la lección 1.2. Si te da tiempo, también el de la 1.1: repasar lo de hace unos días es lo que más fija.

Al terminar podrás: hacer cuentas con enteros y decimales sin caer en la división entera, usar %, convertir con static_cast y escribir condiciones con ==, <, && y ||.

Por qué importa. Toda decisión de un programa es una pregunta del tipo «¿esto es menor que aquello?» o «¿esto Y aquello?». Recorrer una lista enlazada es repetir mientras actual != nullptr; una pila vacía es tope == nullptr. Los operadores de esta lección son las piezas con las que se escriben esas preguntas.

1. Los aritméticos: + - * /

int a{10}, b{3};
cout << a + b << "\n";    // 13
cout << a - b << "\n";    // 7
cout << a * b << "\n";    // 30
cout << 2 + 3 * 4 << "\n"; // 14: * y / van antes que + y -
cout << (2 + 3) * 4;      // 20: los paréntesis mandan

El orden es el de la escuela. Si dudas, pon paréntesis: no cuestan nada y aclaran.

2. La división: entera o real

La regla que más errores causa en el primer semestre:

Si los DOS lados de / son enteros, el resultado es entero: los decimales se tiran.

cout << 7 / 2;      // 3    (int / int → int; no redondea, corta)
cout << 7.0 / 2;    // 3.5  (basta con que UNO sea double)
cout << -7 / 2;     // -3   (corta hacia el cero)

Error típico: guardar en double no salva la división entera.

int suma{7};
double promedio = suma / 2;   // 3, no 3.5

C++ calcula primero suma / 2 (int entre int = 3) y después guarda ese 3 en el double. El decimal ya se perdió. Hay que convertir antes de dividir (sección 4).

3. El resto: %

a % b da lo que sobra al dividir a entre b. Solo funciona con enteros.

cout << 17 % 5;     // 2   (17 = 5·3 + 2)
cout << 10 % 2;     // 0   → 10 es par
cout << 1234 % 10;  // 4   → la última cifra
cout << 135 / 60;   // 2   horas completas
cout << 135 % 60;   // 15  minutos que sobran

Pareja clásica: / da cuántas veces cabe, % da lo que sobra. Un detalle: con negativos el resto es negativo. -7 % 2 vale -1, no 1. Por eso «es par» se pregunta con n % 2 == 0, que funciona siempre.

4. Convertir tipos: static_cast

Para pedir una conversión de forma explícita se usa static_cast<tipo>(valor):

int suma{7};
double promedio = static_cast<double>(suma) / 2;  // 3.5 ✓
int truncado = static_cast<int>(3.9);             // 3   (corta, no redondea)

En la primera línea, suma se convierte a double antes de dividir, así que la división ya es real. Fíjate en el sitio de los paréntesis: static_cast<double>(suma / 2) estaría mal: convierte el 3 cuando ya es tarde.

Algunas conversiones ocurren solas (de int a double, por ejemplo). Con static_cast dejas claro que lo haces a propósito.

5. Comparar: == != < > <= >=

Una comparación es una pregunta: su respuesta es un bool.

int nota{14};
bool aprobado = nota >= 10;   // true
cout << (nota == 20);         // 0  (false)  — igual a
cout << (nota != 20);         // 1  (true)   — distinto de

Ojo: preguntar si son iguales es == (dos signos). Uno solo, =, asigna. Lo verás a fondo en la lección 1.4, porque allí es donde muerde. Al mostrar una comparación con cout, ponla entre paréntesis.

Con double, evita ==: 0.1 + 0.2 == 0.3 da false, porque los decimales se guardan de forma aproximada. Se compara con un margen pequeño (el miniproyecto lo hace así en sus pruebas).

6. Lógicos: &&, ||, !

Sirven para unir preguntas:

OperadorSe leeEs true cuando…
a && ba Y blas dos son verdad
a || ba O bal menos una es verdad
!aNO aa es falsa
int edad{20};
bool tieneEntrada{true};
bool entra = edad >= 18 && tieneEntrada;      // true
bool fueraDeRango = edad < 0 || edad > 120;  // false
bool sinEntrada = !tieneEntrada;             // false

Un rango se escribe con dos comparaciones: 0 <= nota && nota <= 20. La forma de la escuela, 0 <= nota <= 20, compila pero no hace lo que parece.

Dato útil: si en a && b la a ya es falsa, b ni se evalúa. Esto se llama evaluación en cortocircuito y lo usarás con apuntadores: p != nullptr && p->dato == 5 nunca toca un apuntador nulo.

7. Atajos: ++, --, += y compañía

int x{5};
x++;        // x = x + 1  → 6
x--;        // x = x - 1  → 5
x += 10;    // x = x + 10 → 15
x -= 3;     // x = x - 3  → 12
x *= 2;     // x = x * 2  → 24
x /= 5;     // x = x / 5  → 4  (división entera)
x %= 3;     // x = x % 3  → 1

Existen x++ y ++x; solos en su línea hacen lo mismo. La diferencia aparece si los metes dentro de otra expresión. Consejo: úsalos solos en su línea y te ahorras líos.

¿Qué pasa en la memoria?

Cuando escribes suma / 2, el resultado (3) no tiene caja propia ni nombre: es un valor temporal. Existe solo mientras se evalúa esa línea (normalmente en un registro del procesador; tú no lo ves) y luego se copia en la caja de destino o se pierde.

Convertir tampoco toca la variable. static_cast<double>(suma) crea un valor nuevo, 7.0, y suma sigue siendo un int que vale 7. Lo mismo pasa al comparar: nota >= 10 produce un bool temporal, y solo si lo guardas en aprobado ocupa una caja. Los atajos como x += 10 sí escriben en la caja de x: la misma, no una nueva.

Miniproyecto 1.3 · Cuentas que no engañan

Abre ejercicios/03-operadores.cpp. Cinco funciones cortas, cada una con una línea de relleno que tienes que cambiar. Escribe solo dentro de las llaves (qué es una función, en la lección 1.6).

  1. horasCompletas y minutosSobrantes: 135 minutos son 2 h y 15 min.
  2. promedio(a, b): con decimales, sin caer en la división entera.
  3. esImpar(n): que funcione también con negativos.
  4. puedeEntrar(edad, tieneEntrada): 18 años o más y con entrada.

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 03-operadores.cpp -o prog && ./prog

Terminaste cuando salgan todas en ✓. Unos 15 minutos.

Si te atascas: si esImpar(7) sale bien pero esImpar(-3) no, estás comparando el resto con 1; recuerda que -3 % 2 vale -1. Si el promedio da 3 en lugar de 3.5, revisa dónde pusiste el static_cast. La solución está en soluciones/03-operadores.cpp; ábrela solo después de intentarlo de verdad.
