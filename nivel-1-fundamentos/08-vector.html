std::vector

El arreglo que crece solo y sabe su tamaño. Cierra el Nivel 1. ~35 minutos.

Al terminar podrás: crear un vector, añadirle elementos con push_back, recorrerlo con un for de rango, devolverlo desde una función y armar una matriz con un vector de vectores.

Calentamiento (2 minutos): antes de empezar, repite sin mirar el quiz de la lección 1.7 · Arreglos y strings. Y, para que no se oxide, el de la 1.5 · Bucles.

Por qué importa. En C++ real casi nadie usa arreglos sueltos: usa vector. Es el contenedor por defecto. Y es un buen anticipo del Nivel 3: un vector es una estructura de datos que alguien ya programó por ti, con push_back y size, igual que tú programarás tu propia pila con push y tamano.

1. Crear un vector

#include <vector>

vector<int> a = {3, 1, 4};      // con valores: 3 1 4
vector<int> b(5, 0);            // 5 elementos, todos 0 — ojo: paréntesis
vector<string> nombres;         // vacío, de strings

Entre < > va el tipo de lo que guarda. Todos los elementos son del mismo tipo.

2. push_back, size y []

vector<int> v;           // vacío: v.size() es 0
v.push_back(10);         // añade al final → {10}
v.push_back(20);         // → {10, 20}
cout << v.size();        // 2 — lo sabe solo, no hace falta llevar la cuenta
cout << v[0];            // 10 — igual que un arreglo
v[1] = 25;               // → {10, 25}
v.pop_back();            // quita el último → {10}
if (v.empty()) { }       // ¿está vacío?

3. at(): el acceso que avisa

v[i] no comprueba nada, igual que en los arreglos. v.at(i) sí: si i se sale, el programa se detiene con un mensaje (std::out_of_range) en vez de leer basura en silencio.

vector<int> v = {1, 2};
cout << v.at(5);    // se detiene: "terminate called ... out_of_range"

Mientras aprendes, at() te ahorra horas de buscar errores. Cómo «atrapar» ese aviso se ve en la lección 4.4 · Excepciones.

4. El for de rango

Para recorrer todo el vector sin índices:

vector<int> v = {3, 1, 4};
for (int x : v) {            // "para cada x en v"
    cout << x << " ";        // 3 1 4
}

x es una copia de cada elemento: si la cambias, el vector no cambia. Para leer es perfecto. Cuando necesites la posición (o modificar), usa el for de siempre con índice. Funciona también con string y con arreglos.

5. Vectores y funciones

Aquí el vector se porta como un int, no como un arreglo: se pasa una copia. Para «sacar» un resultado, devuélvelo:

vector<int> pares(int n) {        // devuelve un vector entero
    vector<int> r;
    for (int i = 0; i <= n; i += 2) r.push_back(i);
    return r;
}

vector<int> p = pares(8);         // {0, 2, 4, 6, 8}

Copiar un vector grande en cada llamada es lento. La solución (const vector<int>&) es lo primero que ves en el Nivel 2. Y devolverlo, como arriba, es barato: el porqué llega en la lección 4.7.

6. Matriz: un vector de vectores

vector<vector<int>> m = {
    {1, 2, 3},
    {4, 5, 6}
};                                   // 2 filas, 3 columnas
cout << m[1][0];                     // 4 — fila 1, columna 0
cout << m.size() << m[0].size();     // 2 y 3: filas y columnas

vector<vector<int>> t(3, vector<int>(4, 0));   // 3 filas de 4 ceros

for (vector<int> fila : m) {         // recorrer: dos for anidados
    for (int x : fila) cout << x << " ";
    cout << "\n";
}

Tres trampas del vector:

1. v[0] = 5 en un vector vacío. No crea el elemento: escribe fuera. Para añadir, push_back. Para usar [], el elemento tiene que existir ya (por ejemplo con vector<int> v(10, 0);).

2. v.size() - 1 con el vector vacío. size() no tiene signo: 0 − 1 no da −1, da un número gigante. Si recorres al revés, convierte antes: int n = static_cast<int>(v.size());

3. Llaves y paréntesis no son lo mismo. vector<int> v(5); son cinco ceros; vector<int> v{5}; es un solo elemento, el 5.

Los arreglos siguen apareciendo en exámenes y en código antiguo, y por dentro un vector es un arreglo que se agranda solo (en la lección 2.3 verás cómo, con new[]). Por eso aprendiste los dos.

¿Qué pasa en la memoria?

Un vector tiene dos partes. En el marco de main hay un objeto pequeño, siempre del mismo tamaño, que sabe dónde están los datos y cuántos hay. Los elementos van en el montón (heap), en cajas pegadas como las de un arreglo.

v (en el marco de main)
size: 2
capacity: ≥ 2
dónde están los datos →
en el montón
[10] [20] [ libre ]
la capacidad puede sobrar

size() es cuántos elementos hay; capacity(), para cuántos hay sitio reservado. Si haces push_back y ya no queda sitio, el vector reserva un espacio más grande, copia allí los elementos y libera el viejo: los datos se mudan, y cualquier dirección vieja deja de valer. Copiar un vector (como en agregar(a)) copia todos los elementos a un espacio nuevo del montón: por eso cuesta. Y cuando v muere, él mismo libera su parte del montón: es su dueño.

Antes de pasar al Nivel 2

El Nivel 2 (memoria y POO) da por hecho que lo de abajo te sale sin mirar apuntes. No hace falta perfección: hace falta que no tengas que pensar la sintaxis, para que toda tu atención vaya a &, * y las clases.

Debes poder escribir de memoria:

  1. Un programa completo: #include, using namespace std;, int main(), cout, cin; compilarlo con g++ -std=c++17 -Wall y entender el primer error que salga (1.1).
  2. Variables int, double, char, bool, string, const, y una división real con static_cast<double> (1.2–1.3).
  3. Un if / else if / else y un switch con break (1.4).
  4. Un for (int i = 0; i < n; i++), un while con su condición de parada y un menú con do-while (1.5).
  5. Una función con parámetros y return, su prototipo, y explicar por qué cambiar un parámetro no cambia la variable de fuera (1.6).
  6. Recorrer un arreglo pasado con su tamaño: suma, mayor, búsqueda que devuelve −1 (1.7).
  7. Con string: size, [], +, substr, find con npos, getline (1.7).
  8. Con vector: crear, push_back, for de rango, devolverlo desde una función, y una matriz vector<vector<int>> (1.8).

La prueba de los 15 minutos. Sin mirar nada, escribe un programa que lea números con cin hasta que el usuario escriba 0, los guarde en un vector y muestre: cuántos hay, el promedio, el mayor, y cuántos superan el promedio. Usa al menos dos funciones tuyas.
