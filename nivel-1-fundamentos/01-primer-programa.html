Primer programa

Escribir, compilar y ejecutar. Y no asustarse con los errores. ~35 minutos.

Al terminar podrás: escribir un programa en C++ que muestra texto y lee un dato, compilarlo con g++ en la terminal, ejecutarlo y entender qué te dice un error de compilación.

Por qué empezamos aquí. Todo lo que harás en el curso —listas, pilas, colas, clases— sigue el mismo ciclo: escribes el código, lo compilas y lo ejecutas. Si ese ciclo te sale solo, toda tu atención queda libre para lo difícil. Y en la universidad, el primer obstáculo casi nunca es la idea: es un error de compilación que no se sabe leer.

1. Qué es compilar

El procesador no entiende C++. Solo entiende código máquina: ceros y unos. Un compilador es un programa que traduce tu texto en C++ a código máquina. Nosotros usaremos g++, el compilador de C++ de GNU (gratis, viene en Linux).

hola.cpp
tu texto en C++
lo escribes tú
g++
el traductor
revisa y traduce
hola
programa listo
lo ejecutas con ./hola

Dos ideas que conviene separar desde el día uno:

  • Compilar = traducir. Si hay errores de escritura, g++ se niega y te dice dónde.
  • Ejecutar = poner a andar el programa ya traducido. Aquí aparecen los errores de lógica.

Si cambias el .cpp, tienes que volver a compilar. El programa viejo no se entera solo.

2. Abrir la terminal y comprobar que tienes g++

La terminal es una ventana donde escribes órdenes en lugar de hacer clic. En Linux (Ubuntu y parecidos) se abre con Ctrl + Alt + T, o buscando «Terminal» en el menú.

Escribe esto y pulsa Enter:

g++ --version

Si ves algo como esto, ya lo tienes (el número puede ser otro; vale cualquiera de 9 en adelante):

g++ (Ubuntu 15.2.0-16ubuntu1) 15.2.0

Si dice command not found u «orden no encontrada», instálalo (Ubuntu/Debian):

sudo apt install g++      # pide tu contraseña; al escribirla no se ve nada, es normal

Tres órdenes más que usarás siempre:

mkdir cpp      # crea una carpeta llamada cpp
cd cpp         # entra en ella
ls             # lista lo que hay dentro

El código lo escribes en cualquier editor de texto (el «Editor de texto» de Ubuntu, VS Code…) y lo guardas con extensión .cpp en esa carpeta.

¿Usas Windows? Tienes dos caminos. Elige uno:

  • MSYS2: instala g++ de forma nativa (versión MinGW). Sigue la guía oficial de MSYS2; Microsoft explica el mismo proceso paso a paso en Using GCC with MinGW.
  • WSL: un Ubuntu dentro de Windows. Con la guía oficial de WSL (en español) y luego sudo apt install g++. Así todo el curso funciona igual que en Linux.

En Windows el programa se llama hola.exe y en MSYS2 se ejecuta igual, con ./hola.

3. El primer programa, línea por línea

Guarda esto como hola.cpp:

#include <iostream>      // trae las herramientas de entrada y salida (cout, cin)
using namespace std;      // para escribir cout en vez de std::cout

int main() {              // aquí empieza SIEMPRE el programa
    cout << "Hola, mundo!" << "\n";   // muestra el texto y salta de línea
    return 0;             // "terminé bien"
}
  • #include <iostream>: pide prestada una biblioteca, código que ya viene hecho. Sin ella, cout no existe.
  • int main() { ... }: la función principal. El programa empieza en la primera línea dentro de sus llaves y termina en la última.
  • cout << algo: manda algo a la pantalla. Puedes encadenar: cout << "a" << "b".
  • "\n": salto de línea. Sin él, lo siguiente sale pegado en la misma línea.
  • ;: cada instrucción termina en punto y coma. Es el punto final de la frase.
  • return 0;: avisa al sistema de que todo salió bien.

C++ distingue mayúsculas: Main o Cout no son lo mismo que main y cout.

Sobre using namespace std;. Todo lo de la biblioteca estándar vive en un «apellido» llamado std: su nombre completo es std::cout. Esa línea te ahorra escribir std:: y la usaremos en los ejercicios. En proyectos grandes se evita, porque mete cientos de nombres de golpe y alguno puede chocar con los tuyos. Por eso verás std::cout en código profesional.

4. Compilar y ejecutar

En la terminal, dentro de la carpeta donde está hola.cpp:

g++ -std=c++17 -Wall hola.cpp -o hola && ./hola
TrozoQué hace
g++llama al compilador
-std=c++17usa la versión C++17 del lenguaje
-Wallmuestra todos los avisos (warnings): cosas que compilan pero huelen a error
hola.cppel archivo que traduce
-o holacómo se llamará el programa resultante (o = output, salida)
&& ./holasi compiló bien, lo ejecuta. ./ significa «el de esta carpeta»

Debe salir Hola, mundo!. Si cambias el texto, repite la orden completa: la flecha ↑ del teclado recupera la última orden.

5. Leer datos con cin

cout muestra; cin lee lo que el usuario escribe. Las flechas apuntan hacia donde viaja el dato: cout << hacia la pantalla, cin >> hacia tu variable.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nombre;                 // una caja para guardar texto
    int edad;                      // una caja para guardar un número entero

    cout << "¿Cómo te llamas? ";
    cin >> nombre;                 // espera a que escribas y pulses Enter
    cout << "¿Cuántos años tienes? ";
    cin >> edad;

    cout << "Hola, " << nombre << ". El año que viene tendrás " << edad + 1 << ".\n";
    return 0;
}

string e int son tipos de variable; los verás a fondo en la lección 1.2. Un detalle: cin >> nombre lee hasta el primer espacio. Si escribes «Ana María», solo guarda «Ana». Para leer una línea entera hay otra herramienta (getline, lección 1.7).

6. Comentarios

Un comentario es texto para personas: el compilador lo ignora.

// Esto es un comentario de una línea.
cout << "Hola";   // también puede ir al final de una línea

/* Esto es un comentario
   de varias líneas. */

Úsalos para explicar el porqué, no para repetir lo que ya dice el código. Truco útil: poner // delante de una línea la «apaga» sin borrarla.

7. Leer un error de compilación

Quita el ; después de "\n" en hola.cpp y compila. Sale esto (los mensajes de g++ suelen venir en inglés):

hola.cpp: In function ‘int main()’:
hola.cpp:5:35: error: expected ‘;’ before ‘return’
    5 |     cout << "Hola, mundo!" << "\n"
      |                                   ^
      |                                   ;
    6 |     return 0;

Se lee así:

  1. hola.cpp:5:35: archivo, línea 5, columna 35. Ve ahí primero.
  2. error: o warning:. Un error impide compilar. Un warning (aviso) deja compilar, pero casi siempre señala un fallo real. Trátalos igual.
  3. El texto: expected ';' before 'return' = «esperaba un ; antes de return».
  4. El dibujo con ^ marca el punto exacto. Aquí hasta te propone el ; que falta.

El error típico: falta un ; y el mensaje señala la línea de abajo.

El compilador solo se da cuenta de que faltaba algo cuando ve lo siguiente. Si la línea marcada parece perfecta, mira la de arriba.

Y si salen 20 errores, arregla solo el primero y vuelve a compilar. Muchos de los demás son consecuencia de ese primero y desaparecen solos.

¿Qué pasa en la memoria?

Cuando ejecutas ./hola, el sistema carga tu programa en la memoria y la reparte en zonas. Las instrucciones que tradujo g++ van a la zona de código: ahí se leen, no cambian. Al arrancar main, se le reserva un espacio propio, su marco, en la memoria automática (la pila de llamadas o stack). En ese marco viven las cajas nombre y edad del ejemplo de cin.

zona de código
las instrucciones de main
las escribió g++; no cambian
memoria automática
marco de main
nombre
"Ana"
edad
20

cout no se queda con tus datos: solo los lleva a la pantalla. Lo que lees con cin, en cambio, sí se guarda: en la caja de tu variable. Al llegar a return 0;, el marco de main desaparece y el sistema recupera toda la memoria del programa. (Las letras de un string pueden guardarse en otro sitio: lo verás en la lección 1.7.)

Abre ejercicios/01-primer-programa.cpp. Tiene tres partes vacías y unas pruebas que se corrigen solas. Escribe solo dentro de las llaves { } de cada parte: son funciones, y qué es una función lo verás en la lección 1.6. Por ahora, piensa en cada una como un mini-main.

  1. saludar(): muestra exactamente ¡Hola, mundo! y un salto de línea.
  2. cuadro(): dibuja un cuadro de tres líneas con C++ dentro.
  3. sumaEnPantalla(a, b): muestra 2 + 3 = 5. La línea ya está casi hecha; arréglala.

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 01-primer-programa.cpp -o prog && ./prog

Al principio verás todo en ✗. Terminaste cuando salgan todas en ✓. Unos 15 minutos.

Extra opcional (con teclado): crea tu propio presentacion.cpp que pregunte tu nombre y tu carrera con cin y responda «Mucho gusto, …». Luego quita un ; a propósito y lee el error. Romper cosas adrede es la forma más rápida de perderles el miedo.

Si te atascas: compara carácter a carácter con el enunciado. Las pruebas piden la salida exacta: un espacio de más o un "\n" que falta ya cuenta como ✗. La solución está en soluciones/01-primer-programa.cpp; ábrela solo después de intentarlo de verdad.
