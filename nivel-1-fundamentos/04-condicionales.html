Condicionales

El programa elige un camino según una pregunta. ~30 minutos.

Calentamiento (3 minutos). Antes de empezar, repite sin mirar el quiz de la lección 1.3. Las condiciones de hoy están hechas con sus operadores (==, &&, %), así que es el mejor repaso.

Al terminar podrás: hacer que un programa decida con if / else if / else, elegir entre muchos casos con switch, escribir decisiones cortas con el operador ternario y evitar el error de = por ==.

Por qué importa. Casi todas las funciones de una estructura de datos empiezan con una decisión: «¿la lista está vacía?», «¿es el primer nodo?», «¿la pila tiene algo que sacar?». Un if mal escrito ahí es un programa que se cae. Esta lección es la base de todo eso.

1. if: hacer algo solo si se cumple

int nota{14};
if (nota >= 10) {
    cout << "Aprobado\n";      // solo se ejecuta si la condición es true
}
cout << "Fin\n";               // esto se ejecuta siempre

La condición va entre paréntesis y es cualquier expresión que dé bool. Lo que va entre las llaves { } se llama bloque.

2. else: el otro camino

if (nota >= 10) {
    cout << "Aprobado\n";
} else {
    cout << "Reprobado\n";     // cuando la condición es false
}

Siempre se ejecuta uno de los dos bloques, nunca los dos ni ninguno.

3. else if: varios caminos

if (nota < 0 || nota > 20) {
    cout << "Nota inválida\n";
} else if (nota >= 16) {
    cout << "Excelente\n";
} else if (nota >= 10) {
    cout << "Aprobado\n";     // aquí ya sabes que nota < 16
} else {
    cout << "Reprobado\n";
}

Se revisan de arriba abajo y se ejecuta solo el primero que sea verdadero; los demás se saltan. Por eso el orden importa: si pusieras primero nota >= 10, un 18 diría «Aprobado» y nunca llegaría a «Excelente». Un buen hábito: descarta primero los casos inválidos.

4. Llaves siempre

Sin llaves, el if solo gobierna la siguiente instrucción. La sangría (los espacios a la izquierda) no cuenta para nada:

if (saldo < 0)
    cout << "Saldo negativo\n";
    cout << "Cuenta bloqueada\n";   // ¡se ejecuta SIEMPRE! no está dentro del if

Pon llaves siempre, aunque sea una sola línea. Te ahorra este error.

5. El error más famoso: = en lugar de ==

= asigna; == compara. Esto compila:

int x{5};
if (x = 7) {                // ASIGNA 7 a x; luego pregunta "¿7 es verdadero?" → sí
    cout << "x vale 7\n";   // se ejecuta siempre, y además x ya vale 7
}

Cualquier número distinto de 0 cuenta como true, así que la condición «siempre se cumple». Con -Wall, g++ te avisa:

warning: suggest parentheses around assignment used as truth value [-Wparentheses]

Si ves ese aviso, casi seguro querías ==. Por eso compilamos siempre con -Wall.

Otro despiste parecido: un ; justo después del paréntesis, if (x > 5);, termina el if ahí mismo. El bloque de abajo se ejecuta siempre.

6. switch: elegir por un valor exacto

Cuando comparas la misma variable con muchos valores fijos, switch se lee mejor que una cadena de else if:

int opcion{2};
switch (opcion) {
    case 1:
        cout << "Agregar\n";
        break;                 // sal del switch
    case 2:
        cout << "Eliminar\n";
        break;
    case 3:
        cout << "Listar\n";
        break;
    default:                   // ningún case coincidió
        cout << "Opción inválida\n";
        break;
}
  • Salta al case que coincide y ejecuta desde ahí.
  • break sale del switch. Si lo olvidas, sigue ejecutando los case de abajo (se llama fallthrough, «caer a través»).
  • default es el «si no»: se usa cuando ningún case coincide.
  • Solo funciona con enteros y char: no con string ni con double, y no admite rangos como «de 10 a 15». Para eso, if.

Es la herramienta típica de los menús de consola: «1. Agregar, 2. Eliminar, 3. Listar». Harás muchos con pilas y colas.

7. El operador ternario: un if en una línea

int a{4}, b{9};
int mayor = (a > b) ? a : b;          // 9
cout << (nota >= 10 ? "Aprobado" : "Reprobado");

Se lee: «¿condición? si sí, esto : si no, esto otro». Sirve para elegir un valor, no para ejecutar varios pasos. Úsalo solo cuando quepa cómodo en una línea; si no, un if es más claro.

¿Qué pasa en la memoria?

Las llaves de un if no solo agrupan instrucciones: también marcan cuánto viven las variables declaradas dentro. Una variable de bloque nace cuando el programa entra en el bloque y muere en su }:

int nota{14};                      // vive todo main
if (nota >= 10) {
    string mensaje = "Aprobado";   // nace aquí...
    cout << mensaje;
}                                  // ...y muere aquí
cout << mensaje;                   // error: 'mensaje' was not declared in this scope

Si la condición es falsa, mensaje ni siquiera llega a existir. Hay dos ideas distintas: el ámbito es dónde se puede usar el nombre (desde su declaración hasta la }), y el tiempo de vida es cuándo existe la caja en la memoria. Para las variables locales de este nivel coinciden; más adelante verás casos en que no. Todas ellas viven en el marco de main, en la memoria automática (la pila de llamadas o stack).

Abre ejercicios/04-condicionales.cpp. Cuatro funciones con relleno; escribe solo dentro de las llaves (qué es una función, en la lección 1.6).

  1. clasificarNota(nota): «invalida», «reprobado», «aprobado» o «excelente» en la escala del 0 al 20. Con if / else if / else.
  2. nombreDia(dia): de 1 a 7, el nombre del día; si no, «invalido». Con switch.
  3. valorAbsoluto(n): en una línea, con el ternario.
  4. esBisiesto(anio): la regla del calendario, combinando %, && y ||.

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 04-condicionales.cpp -o prog && ./prog

Terminaste cuando salgan todas en ✓. Unos 20 minutos.

Extra opcional (con teclado): escribe un calculadora.cpp que lea dos números y una operación ('+', '-', '*', '/') con cin y use un switch sobre ese char. Que avise si se intenta dividir entre cero.
