Referencias y const

Otro nombre para la misma variable. ~30 minutos.

Al terminar podrás: escribir funciones que cambian las variables de quien las llama con &, y pasar un string o un vector grande con const & para no copiarlo.

Antes de empezar: repite sin mirar el quiz de la lección 1.8 · vector. Dos minutos. Recordar lo de ayer es lo que hace que no se te olvide.

Por qué. Hasta ahora toda función recibía una copia de lo que le pasabas (lección 1.6). Eso tiene dos problemas: la función no puede cambiar tus variables, y copiar un vector de un millón de números es lento. Las referencias resuelven los dos. Además, son la puerta de entrada a los apuntadores (lección 2.2), que son el corazón de las listas, pilas y colas de la universidad.

1. Una referencia es otro nombre

Una referencia es un segundo nombre para una variable que ya existe. Se declara con & después del tipo:

int x = 5;
int& r = x;    // r es otro nombre de x. No hay una variable nueva.

r = 9;         // escribir en r es escribir en x
cout << x;     // 9
x = 2;
cout << r;     // 2  — es la misma casilla
x (alias: r)
valor: 9
una sola casilla, dos nombres

Compáralo con una copia normal, donde sí hay dos casillas:

int x = 5;
int c = x;     // c es una COPIA: casilla aparte
c = 9;
cout << x;     // 5  — x no se entera
x
valor: 5
c
valor: 9

2. Dos reglas de las referencias

Regla 1: nace pegada a algo. Una referencia hay que inicializarla al declararla. int& r; a secas no compila: ¿otro nombre de qué?

Regla 2: no se puede despegar. Una vez que r es otro nombre de x, lo es para siempre. Un = posterior copia el valor, no cambia a quién se refiere:

int x = 5, y = 7;
int& r = x;
r = y;          // NO hace que r sea otro nombre de y:
                // copia el 7 dentro de x
cout << x;      // 7

Guarda estas dos reglas: en la lección 2.2 verás que el apuntador hace justo lo contrario en las dos (puede valer nullptr y puede cambiar de destino).

3. Paso por referencia: la función toca tu variable

Aquí está la utilidad de verdad. Mira la función de siempre, que recibe una copia:

void doblar(int n) { n = n * 2; }    // dobla la COPIA

int a = 4;
doblar(a);
cout << a;    // 4  — no cambió

Añade un solo & al parámetro y n pasa a ser otro nombre de a:

void doblar(int& n) { n = n * 2; }   // n ES la variable de quien llama

int a = 4;
doblar(a);    // se llama igual que siempre, sin nada raro
cout << a;    // 8

Esto se llama paso por referencia. Fíjate en que la llamada doblar(a) se ve igual que antes: el cambio está solo en la firma de la función.

Guarda este ejemplo. En la lección 2.2 vas a escribir el mismo doblar con un apuntador (int*). Hará lo mismo, pero con más símbolos: *n dentro y &a al llamar. Comparar las dos versiones es la mejor forma de entender las dos.

Devolver dos resultados

Una función solo tiene un return. Con referencias puede dejar varios resultados en variables de quien llama:

void dividir(int a, int b, int& cociente, int& resto) {
    cociente = a / b;
    resto = a % b;
}

int c = 0, r = 0;
dividir(17, 5, c, r);
cout << c << " " << r;   // 3 2

El error típico: olvidar el &. Si escribes void doblar(int n) cuando querías int& n, el programa compila sin quejarse. La función cambia una copia, tu variable sigue igual y no hay ningún aviso. Si una función «no hace nada», mira primero si le falta el &.

Y al revés: doblar(5) no compila con int& n. Un 5 no es una variable; no se le puede poner otro nombre.

4. const &: sin copia y sin tocar

Pasar un string o un vector por valor copia todos sus elementos. Con & no se copia nada, pero entonces la función podría cambiarlo. Si solo quieres leer, usa const &: referencia (no copia) que no deja modificar.

int sumar(const vector<int>& v) {   // no copia el vector
    int total = 0;
    for (int x : v) total += x;
    return total;
}

void saludar(const string& nombre) {
    cout << "Hola, " << nombre;
    nombre = "otro";                 // ERROR de compilación: es const
}

El compilador te protege: si por error intentas cambiar algo const, no compila. Además, const & sí acepta valores sueltos: saludar("Ana") funciona.

¿Cuál uso? La regla corta

QuieresTipo pequeño (int, double, char, bool)Tipo grande (string, vector, objetos)
Solo leerpor valor: int nconst string& s
Cambiar la variable de quien llamaint& nvector<int>& v

Un int se copia tan rápido como una referencia, así que para leerlo basta pasarlo por valor (LearnCpp, sección «When to use pass by value vs pass by reference»).

5. Referencias en el for de rango

Lo mismo pasa en el for que viste con vector. Sin &, cada vuelta trabaja con una copia:

vector<int> v = {1, 2, 3};

for (int x : v)  x = x * 10;   // cambia copias: v sigue {1, 2, 3}
for (int& x : v) x = x * 10;   // x es cada elemento: v queda {10, 20, 30}

vector<string> nombres = {"Ana", "Luis"};
for (const string& s : nombres) cout << s;   // leer sin copiar cada string

¿Qué pasa en la memoria?

Cada llamada a una función ocupa un marco: su espacio en la memoria automática (la pila de llamadas o stack). Con int& r = x; en ese marco hay una sola caja con dos nombres: piensa en r como una etiqueta más, no como una caja nueva.

Cuando llamas a doblar(a) con int& n, el marco de doblar no guarda una copia de a: n trabaja sobre la caja de a, que sigue en el marco de quien llama. Por eso sumar(const vector<int>& v) no mueve ni un número: los datos del vector se quedan donde estaban.

El peligro va al revés: una función no debe devolver una referencia a una variable suya local. Al hacer return su marco se libera, esa caja deja de existir y la referencia queda pegada a nada.

6. Resumen

EscribesSignifica
int& r = x;r es otro nombre de x (misma casilla)
void f(int& n)la función trabaja sobre la variable de quien llama
void f(const string& s)sin copia y sin permiso para cambiarlo
for (int& x : v)recorrer el vector pudiendo cambiar sus elementos
void f(int n)copia: los cambios no salen de la función

El & tiene dos trabajos. Pegado a un tipo (int& r) declara una referencia: es lo de hoy. Delante de una variable en una expresión (&x) significa «la dirección de x»: eso es de la lección 2.2. Mismo símbolo, ideas distintas.

Todo esto, con los errores típicos, está en la hoja de referencia de referencias y operadores.

Miniproyecto 2.1 · Funciones que tocan tus datos

Abre ejercicios/01-referencias-y-const.cpp. Tiene cuatro funciones vacías y unas pruebas que se corrigen solas. Las firmas ya están escritas: fíjate en cuál lleva & y cuál const &.

  1. ordenarDos(int& a, int& b): deja el menor en a y el mayor en b.
  2. duplicarTodos(vector<int>& v): multiplica por 2 cada elemento del vector de quien llama.
  3. contarMayores(const vector<int>& v, int limite): cuenta cuántos superan el límite, sin copiar el vector.
  4. contarSignos(const vector<int>& v, int& positivos, int& negativos): «devuelve» dos resultados a la vez.

Compílalo desde la carpeta ejercicios:

g++ -std=c++17 -Wall 01-referencias-y-const.cpp -o prog && ./prog

Al principio verás varias ✗. Terminaste cuando salgan todas en ✓. Unos 15 minutos.

Si te atascas: en duplicarTodos, el truco es el for (int& x : v) de la sección 5. En contarSignos, pon los dos contadores a 0 antes del bucle: las pruebas te los pasan con basura a propósito.
