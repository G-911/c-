El molde de una función recursiva

tipo f(problema) {
    if (problema es mínimo) return respuesta directa;   // CASO BASE
    return combinar(un poco, f(problema más pequeño));    // CASO RECURSIVO
}

Dos preguntas para escribirla: 1) ¿cuál es el caso más pequeño y qué respondo? 2) Si alguien ya resolvió el problema un poco más pequeño, ¿qué le añado yo?

Búsqueda binaria (vector ORDENADO)

int busquedaBinaria(const vector<int>& v, int x) {
    int izq = 0, der = (int)v.size() - 1;
    while (izq <= der) {
        int medio = izq + (der - izq) / 2;   // como (izq+der)/2, sin desbordar
        if (v[medio] == x) return medio;
        if (v[medio] < x) izq = medio + 1;   // tiro la mitad izquierda
        else              der = medio - 1;   // tiro la mitad derecha
    }
    return -1;                               // no está
}

Solo vale con datos ordenados y acceso por índice. Sobre datos desordenados da -1 de cosas que sí están, sin avisar. En la biblioteca: std::binary_search (en <algorithm>).

Medir con <chrono>

#include <chrono>
auto inicio = chrono::steady_clock::now();
// ... código a medir ...
auto fin = chrono::steady_clock::now();
cout << chrono::duration<double, milli>(fin - inicio).count() << " ms\n";

Compila con -O2, repite varias veces y compara proporciones: n × 2 → tiempo × 2 es O(n); tiempo × 4 es O(n²).
