Las tres reglas

  1. Cada new tiene exactamente un delete; cada new[], un delete[].
  2. No pierdas la dirección antes de liberar (si no, fuga de memoria).
  3. Después de delete, pon el apuntador a nullptr (si no, apuntador colgante).

El patrón de crecer un arreglo

int* crecer(int* datos, int tam, int nuevaCapacidad) {
    int* nuevo = new int[nuevaCapacidad];              // 1. pedir
    for (int i = 0; i < tam; i++) nuevo[i] = datos[i]; // 2. copiar
    delete[] datos;                                    // 3. liberar el viejo
    return nuevo;                                      // quien llama: datos = crecer(...)
}

Cuando se llena, se duplica la capacidad (1, 2, 4, 8...). Así trabaja por dentro std::vector.
