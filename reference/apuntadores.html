El patrón de la función que modifica

void doblar(int* n) { *n = *n * 2; }   // recibe una dirección, escribe con *

int a = 4;
doblar(&a);                            // pasa la dirección con &   → a vale 8

Sin * en el parámetro (int n) la función recibe una copia y tu variable no cambia.

Las dos caras de *

En una declaración (int* p): «p es un apuntador».
En una expresión (*p = 9): «ve al valor apuntado».
