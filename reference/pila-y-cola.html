Pila y cola

Hoja de consulta rápida. Lecciones 6 y 7.

Las dos usan el mismo nodo que la lista enlazada:

struct Nodo {
    int dato;
    Nodo* siguiente;
    Nodo(int d) : dato(d), siguiente(nullptr) {}
};

Pila (LIFO: el último que entra sale primero)

Una lista donde solo se toca la cabeza, que aquí se llama tope. Ejemplos: pila de platos, deshacer, botón «atrás».

MétodoQué hace
push(x) (apilar)pone x arriba
pop() (desapilar)quita y libera el de arriba; vacía → no hace nada
top()devuelve el de arriba; comprobar vacia() antes
vacia()tope == nullptr
tamano()recorre contando
void Pila::push(int valor) {
    Nodo* nuevo = new Nodo(valor);
    nuevo->siguiente = tope;
    tope = nuevo;
}

void Pila::pop() {
    if (vacia()) return;
    Nodo* viejo = tope;          // 1. guardar
    tope = tope->siguiente;      // 2. mover
    delete viejo;                // 3. borrar
}

int Pila::top() const { return tope->dato; }   // solo si !vacia()

Paréntesis balanceados

Abre → push. Cierra → si la pila está vacía o el top no es su pareja: false; si lo es, pop. Al final: balanceado solo si la pila quedó vacía.

Cola (FIFO: el primero que entra sale primero)

Una lista con un apuntador extra al final. Se entra por final y se sale por frente. Ejemplos: fila del banco, impresora.

Regla que siempre se cumple: frente y final son nullptr a la vez, o ninguno lo es.

MétodoQué hace
encolar(x)añade x por el final
desencolar()quita y libera el del frente; vacía → no hace nada
verFrente()devuelve el del frente; comprobar vacia() antes
vacia()frente == nullptr
tamano()recorre contando
void Cola::encolar(int valor) {
    Nodo* nuevo = new Nodo(valor);
    if (vacia()) {
        frente = nuevo;
        final = nuevo;
    } else {
        final->siguiente = nuevo;   // primero enlazar...
        final = nuevo;              // ...después mover final
    }
}

void Cola::desencolar() {
    if (vacia()) return;
    Nodo* viejo = frente;
    frente = frente->siguiente;
    if (frente == nullptr) final = nullptr;   // ¡salió el último!
    delete viejo;
}
