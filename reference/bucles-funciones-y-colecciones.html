Bucles, funciones y colecciones

Hoja de consulta rápida de las lecciones 1.5 a 1.8.

Bucles (1.5)

for (int i = 0; i < n; i++) { }     // n vueltas: i = 0 … n-1
while (condicion) { }               // pregunta antes; puede no entrar nunca
do { } while (condicion);           // entra al menos una vez; lleva ;
break;                              // sale del bucle ya
continue;                           // salta a la siguiente vuelta
BucleCuándo
forsabes cuántas vueltas
whileparas cuando pase algo (recorrer una lista hasta nullptr)
do-whileal menos una vez (menús, validar una entrada)

Funciones (1.6)

int suma(int a, int b);                 // prototipo (va arriba)
int suma(int a, int b) { return a + b; } // definición
void mostrar(string s) { cout << s; }  // void: no devuelve nada
double area(double b, double h = 1.0);  // por defecto: al final y solo en el prototipo
int maximo(int a, int b);               // sobrecarga: mismo nombre,
int maximo(int a, int b, int c);        //   distintos parámetros

Los parámetros son copias (salvo los arreglos). Las variables locales desaparecen al salir de la función.

Arreglos (1.7)

const int N = 5;
int a[N] = {7, 9, 6, 10, 8};        // índices 0 … N-1; tamaño fijo
for (int i = 0; i < N; i++) cout << a[i];
int sumar(int arr[], int n);        // a una función: SIEMPRE con su tamaño
sumar(a, N);                        // los cambios dentro SÍ se quedan
