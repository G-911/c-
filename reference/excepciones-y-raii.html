El patrón de la Pila que avisa

void pop() {
    if (vacia()) throw out_of_range("pop: pila vacía");   // comprobar ANTES de tocar nada
    Nodo* viejo = tope;
    tope = tope->siguiente;
    delete viejo;
}

try { p.pop(); }
catch (const out_of_range& e) { cout << e.what(); }

RAII en una línea

Un objeto toma el recurso en el constructor y lo suelta en el destructor. El destructor se llama siempre al salir del bloque (return, } o excepción), así que el recurso se libera siempre. Ejemplos: vector, string, ifstream, unique_ptr, shared_ptr.

Lista enlazada con unique_ptr

struct Nodo {
    int dato;
    unique_ptr<Nodo> siguiente;
    Nodo(int d) : dato(d), siguiente(nullptr) {}
};

// insertar al inicio
auto nuevo = make_unique<Nodo>(valor);
nuevo->siguiente = move(cabeza);
cabeza = move(nuevo);

// recorrer
for (Nodo* p = cabeza.get(); p != nullptr; p = p->siguiente.get()) { ... }

// eliminar el primero (se libera solo)
cabeza = move(cabeza->siguiente);

// destructor iterativo: solo para listas MUY largas (evita desbordar la pila)
~ListaEnlazada() { while (cabeza) cabeza = move(cabeza->siguiente); }
