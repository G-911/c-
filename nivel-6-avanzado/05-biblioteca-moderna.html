Biblioteca moderna

Seis herramientas de C++17, C++20 y C++23 que hacen el código más corto y más seguro. ~40 minutos.

Al terminar podrás: devolver «un valor o nada» con optional, guardar «una cosa u otra» con variant y visit, pasar textos y arreglos sin copiarlos con string_view y span (y saber cuándo cuelgan), escribir texto con format/print y encadenar filter, transform y take con ranges.

Antes de empezar: repite sin mirar el quiz de la lección 6.4 (plantillas avanzadas y concepts). Recordar lo de ayer es lo que hace que se quede.

Por qué. Hasta ahora resolvías estos problemas a mano: -1 para decir «no encontrado», un int* más un tamaño para pasar un arreglo, cout << encadenado para formatear, un bucle con if para filtrar. Funciona, pero cada truco tiene su trampa. La biblioteca moderna trae una pieza hecha para cada caso. Es lo que verás en cualquier código C++ actual, y lo que te pedirán en un trabajo.

Qué estándar pide cada una (comprobado en cppreference):

Por eso en esta lección compilamos con -std=c++23: es la única forma de tenerlas todas. Con -std=c++17 solo funcionan las de la primera fila.

1. optional: un valor... o nada

En la lección 4.4 dijimos que si buscar(x) no encuentra nada, lo normal es devolver -1. Pero -1 es un truco: hay que acordarse de comprobarlo, y no sirve si -1 es un dato válido. optional<int> lo dice en el propio tipo: «aquí puede haber un int».

#include <optional>

optional<int> buscar(const vector<int>& v, int x) {
    for (int i = 0; i < (int)v.size(); i++)
        if (v[i] == x) return i;     // hay valor
    return nullopt;                  // no hay valor
}

vector<int> v = {4, 8, 15};
auto r = buscar(v, 8);
if (r) cout << "en la posición " << *r;   // en la posición 1
cout << buscar(v, 99).value_or(-1);        // -1: el valor, o este si no hay
  • if (r) o r.has_value(): ¿hay valor?
  • *r: el valor, sin comprobar nada.
  • r.value(): el valor; si no hay, lanza bad_optional_access.
  • r.value_or(otro): el valor, o otro si no hay.

Error típico: *r sin preguntar antes. Si r está vacío, *r es comportamiento indefinido: no lanza ni avisa, lee lo que haya. Usa *r solo dentro de un if (r). Si no quieres el if, usa value_or.

2. variant y visit: una cosa u otra

Una figura puede ser un círculo o un rectángulo. En la lección 2.6 lo resolviste con herencia: una clase base con virtual, objetos con new y apuntadores a la base. variant es la otra forma: un objeto que guarda exactamente uno de varios tipos, sin herencia ni new.

#include <variant>

struct Circulo    { double radio; };
struct Rectangulo { double ancho, alto; };
using Figura = variant<Circulo, Rectangulo>;   // un Circulo O un Rectangulo

Figura f = Rectangulo{2, 3};
f = Circulo{1};                     // ahora guarda un Circulo; el rectángulo ya no está
cout << f.index();                  // 0: guarda el primer tipo de la lista
cout << holds_alternative<Circulo>(f);   // 1 (true)

Para hacer algo distinto según lo que guarde, se usa visit con un visitante: un objeto con un operator() por cada tipo.

struct CalculaArea {
    double operator()(const Circulo& c) const    { return 3.14159 * c.radio * c.radio; }
    double operator()(const Rectangulo& r) const { return r.ancho * r.alto; }
};

Figura f = Rectangulo{2, 3};
cout << visit(CalculaArea{}, f);   // 6
f = Circulo{1};
cout << visit(CalculaArea{}, f);   // 3.14159

Lo mejor: si añades Triangulo a la Figura y olvidas su operator(), no compila. El compilador te obliga a tratar todos los casos.

3. string_view: mirar un texto sin copiarlo

Un string_view es una ventana a un texto que vive en otro sitio: guarda dónde empieza y cuánto mide. No copia las letras. Es el parámetro ideal para funciones que solo leen texto: acepta un string, un literal "..." o un trozo de otro texto, sin crear ningún string nuevo (LearnCpp 5.8).

#include <string_view>

void saludar(string_view nombre) { cout << "Hola, " << nombre << "\n"; }

saludar("Ana");          // sin crear ningún string
string s = "Bea";
saludar(s);              // tampoco copia s

string_view sv = "abcdef";
cout << sv.substr(1, 3); // bcd: el substr de una vista es otra vista, sin copiar

El peligro: la vista que cuelga. La vista no es dueña del texto. Si el texto muere, la vista sigue apuntando a él:

string saludo() { return "hola, esto es un texto largo"; }

string_view sv = saludo();   // la string temporal muere al final de ESTA línea
cout << sv;                  // mira memoria liberada

Compila sin un solo aviso, incluso con -Wall -Wextra. En esta máquina imprimió basura seguida de « texto largo»; con -fsanitize=address el programa se para con heap-use-after-free. Regla: usa string_view para parámetros. Para guardar un texto (un atributo, una variable que dura), usa string.

4. span: lo mismo, para arreglos

En la lección 1.7, pasar un arreglo a una función pedía dos parámetros: el arreglo y su tamaño. span<const int> (C++20) junta las dos cosas: es una ventana a elementos contiguos, vengan de un arreglo o de un vector.

#include <span>

int sumar(span<const int> datos) {    // const: solo lee
    int s = 0;
    for (int x : datos) s += x;        // sabe su tamaño: datos.size()
    return s;
}

int arr[] = {1, 2, 3};
vector<int> w = {10, 20, 30};
cout << sumar(arr) << " " << sumar(w);   // 6 60

span<const int> sp = w;
cout << sumar(sp.first(2));           // 30: los 2 primeros, sin copiar
cout << sumar(sp.subspan(1));         // 50: desde el índice 1

Igual que string_view, un span no es dueño: si el vector crece (y muda sus datos) o muere, el span cuelga.

5. format y print: texto con huecos

format (C++20) arma un string con huecos {} que se rellenan en orden. println (C++23) hace lo mismo y lo imprime con salto de línea.

#include <format>
#include <print>

string s = format("{} tiene {} años", "Ana", 20);   // "Ana tiene 20 años"
cout << format("{:.2f}", 3.14159);                  // 3.14: dos decimales
cout << format("[{:>5}]", 42);                       // [   42]: ancho 5, a la derecha
cout << format("[{:<5}]", 42);                       // [42   ]: a la izquierda
println("{} + {} = {}", 2, 3, 2 + 3);                // 2 + 3 = 5

Lo que va tras los dos puntos dentro de {} es el formato: .2f (2 decimales), >5 (ancho 5 a la derecha), <5 (a la izquierda). Y una ventaja sobre printf de C: si pones más huecos que valores, no compila (g++ lo comprueba al compilar: «call to consteval function ... is not a constant expression»).

Error típico: olvidar -std=c++23. g++ 15, si no le dices nada, compila en C++17. Entonces println no existe y el error es:

error: ‘println’ is not a member of ‘std’
note: ‘std::println’ is only available from C++23 onwards

No es que lo escribieras mal: es el estándar. Lo mismo pasa con format, span y ranges si compilas en C++17.

6. Ranges y vistas: encadenar sin bucles

Los algoritmos de la lección 4.3 pedían begin() y end(). Con ranges (C++20) se pasa el contenedor entero: ranges::sort(v);. Y llegan las vistas: pasos que se encadenan con |, como una tubería.

#include <ranges>
#include <algorithm>

vector<int> u = {5, 2, 8, 1, 9, 4};
ranges::sort(u);                                   // 1 2 4 5 8 9

auto vista = u | views::filter([](int x) { return x % 2 == 0; })   // pares: 2 4 8
               | views::transform([](int x) { return x * x; })     // al cuadrado: 4 16 64
               | views::take(2);                                   // los 2 primeros
for (int x : vista) cout << x << " ";              // 4 16

vector<int> z = vista | ranges::to<vector>();     // C++23: la vista, a vector

Una vista es perezosa: no calcula nada al crearla, solo cuando la recorres, y de uno en uno. Compruébalo:

vector<int> v = {1, 2, 3};
auto vista = v | views::transform([](int x) { cout << "[" << x << "]"; return x * 2; });
cout << "antes ";
for (int x : vista) cout << x << " ";
// Muestra: antes [1]2 [2]4 [3]6

«antes» sale primero: crear la vista no llamó a la lambda. Y como una vista no copia v sino que lo mira, tampoco es dueña: si v deja de existir, la vista cuelga igual que un string_view.

¿Qué pasa en la memoria?

Dos familias. optional y variant guardan el valor dentro de sí mismos, en el mismo sitio donde vivan (normalmente el marco de la función, en la memoria automática o stack): no hacen new. Un optional<int> es el int más una marca de «hay / no hay»; un variant mide lo que su tipo más grande, más un número que dice cuál guarda (y algo de relleno).

string_view, span y las vistas de ranges son lo contrario: solo guardan dónde empiezan los datos y cuántos son. Los datos los tiene su dueño (un string, un vector, a menudo en el montón). Su tiempo de vida no está atado al del dueño: si el dueño muere antes, la vista es un apuntador colgante con otro nombre.

cout << sizeof(optional<int>) << " " << sizeof(string_view) << " " << sizeof(span<const int>);
// g++ 15, 64 bits: 8 16 16  (y sizeof(string) da 32: él sí es dueño de sus letras)
