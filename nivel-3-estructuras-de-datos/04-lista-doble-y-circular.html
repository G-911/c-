Lista doble y lista circular

Una flecha más hacia atrás, o una flecha que vuelve al principio. ~35 minutos.

Al terminar podrás: escribir una lista doble que inserta al final sin recorrer y elimina un nodo reenganchando sus dos vecinos, recorrer una lista circular sin entrar en un bucle infinito, y elegir entre lista simple, doble o circular según el problema.

Antes de empezar: repite sin mirar el quiz de la lección anterior, Lección 3.3 · Lista enlazada II. Recordar lo de hace días es lo que lo fija.

Por qué. En la lista simple solo puedes ir hacia adelante. Para llegar al último hay que recorrerla entera, y para borrar un nodo necesitas arrastrar un segundo apuntador con «el de antes». La lista doble y la circular son las dos variantes que piden en casi todos los cursos de estructuras de datos. Y la doble es, por dentro, el std::list de la biblioteca estándar (cppreference, std::list). Es la misma lista de las lecciones 3.2 y 3.3 con una flecha más.

1. El nodo doble: dos flechas

Al nodo de siempre se le añade un apuntador anterior, que mira al nodo de atrás:

struct Nodo {
    int dato;
    Nodo* anterior;     // el de atrás (nullptr si es el primero)
    Nodo* siguiente;    // el de adelante (nullptr si es el último)

    Nodo(int d) : dato(d), anterior(nullptr), siguiente(nullptr) {}
};

2. La clase ListaDoble: cabeza y último

Ya que hay flechas hacia atrás, vale la pena guardar también el último nodo. Así la lista se puede recorrer desde cualquiera de las dos puntas.

class ListaDoble {
private:
    Nodo* cabeza;    // primer nodo
    Nodo* ultimo;    // último nodo
public:
    ListaDoble() : cabeza(nullptr), ultimo(nullptr) {}   // vacía: los dos en nullptr
};

La regla que nunca se rompe: si A->siguiente es B, entonces B->anterior es A. Cada vez que cambies una flecha, pregúntate cuál es su pareja.

3. Insertar al final sin recorrer

En la lección 3.3, insertarAlFinal caminaba hasta el último nodo. Con ultimo no hace falta: ya sabemos dónde está.

void insertarAlFinal(int valor) {
    Nodo* nuevo = new Nodo(valor);
    if (ultimo == nullptr) {         // lista vacía: es el primero Y el último
        cabeza = nuevo;
        ultimo = nuevo;
        return;
    }
    nuevo->anterior = ultimo;        // 1. el nuevo mira atrás, al viejo último
    ultimo->siguiente = nuevo;       // 2. el viejo último mira adelante, al nuevo
    ultimo = nuevo;                  // 3. ahora el último es él
}

Antes. La lista es 1 ⇄ 2 y el nodo nuevo está creado aparte.

Después. Lo que cambió va en color: las dos flechas entre el 2 y el 3, y ultimo.

insertarAlInicio es el espejo: nuevo->siguiente = cabeza; cabeza->anterior = nuevo; cabeza = nuevo;, con el mismo caso especial de la lista vacía.

4. Eliminar: reenganchar los dos vecinos

Aquí la lista doble brilla. En la simple necesitabas el apuntador anterior del recorrido. Aquí el propio nodo sabe quién va antes. Primero lo buscas; luego haces que sus dos vecinos se salten el nodo:

bool eliminar(int valor) {
    Nodo* actual = cabeza;
    while (actual != nullptr && actual->dato != valor) {
        actual = actual->siguiente;
    }
    if (actual == nullptr) return false;           // vacía o no estaba

    if (actual->anterior != nullptr)
        actual->anterior->siguiente = actual->siguiente;   // el de atrás salta adelante
    else
        cabeza = actual->siguiente;                        // era la cabeza

    if (actual->siguiente != nullptr)
        actual->siguiente->anterior = actual->anterior;    // el de adelante salta atrás
    else
        ultimo = actual->anterior;                         // era el último

    delete actual;                                 // ya nadie apunta a él
    return true;
}

Antes: queremos borrar el 2, y actual ya lo encontró.

Después: el 1 mira adelante al 3, el 3 mira atrás al 1, y el 2 se libera.

Fíjate en los dos if: cubren los cuatro casos de golpe. Borrar en medio (los dos vecinos existen), la cabeza (no hay anterior), el último (no hay siguiente) y el único nodo (no hay ninguno: cabeza y ultimo quedan en nullptr).

Error típico: arreglar solo una dirección. Si haces actual->anterior->siguiente = actual->siguiente; y olvidas la línea de anterior, la lista se ve bien de izquierda a derecha… pero el 3 sigue mirando atrás a un nodo borrado. El día que recorras al revés, lees memoria liberada (apuntador colgante). Por eso en el miniproyecto cada prueba de eliminar comprueba la lista en los dos sentidos. Igual con ultimo: si borras el último y no lo mueves, queda apuntando a un nodo muerto.

5. Recorrer al revés

Es el recorrido de siempre, empezando por el otro extremo y avanzando por la otra flecha:

for (Nodo* actual = ultimo; actual != nullptr; actual = actual->anterior) {
    cout << actual->dato << " ";       // con 1 ⇄ 2 ⇄ 3 muestra: 3 2 1
}

6. La lista circular: el último vuelve a la cabeza

En una lista circular el último nodo no apunta a nullptr: apunta otra vez a la cabeza. La cadena se cierra en un círculo. (Aquí la hacemos con nodos simples; también existe la doble circular.)

Consecuencia directa: no hay nullptr al final. El recorrido de siempre, while (actual != nullptr), no termina nunca. La condición de parada pasa a ser «volví a la cabeza». Como hay que dar al menos un paso antes de comparar, encaja un do-while:

void imprimir() {
    if (cabeza == nullptr) return;          // vacía: nada que hacer
    Nodo* actual = cabeza;
    do {
        cout << actual->dato << " ";
        actual = actual->siguiente;
    } while (actual != cabeza);             // paro al dar la vuelta completa
}
// Con 10 → 20 → 30 → (10) muestra: 10 20 30

Dos detalles más. Con un solo nodo, ese nodo se apunta a sí mismo (nuevo->siguiente = nuevo;). Y el destructor tiene que romper el círculo primero (poner el siguiente del último en nullptr); a partir de ahí es el destructor de la lección 3.2.

Error típico: recorrer una circular con while (actual != nullptr). Nunca llega a nullptr: el programa se queda dando vueltas para siempre. Si dentro del bucle hay un cout, verás números repitiéndose sin fin; si no, parecerá «colgado». Ctrl+C lo detiene. En una circular, la parada es siempre actual != cabeza.

7. ¿Cuándo sirve cada una?

ListaVentajaEjemplos típicos
Simplela más sencilla y ligera: una flecha por nodopila y cola (lecciones 3.6 y 3.7), listas que solo se recorren hacia adelante
Dobleir hacia atrás; borrar un nodo conocido sin buscar su anterior; insertar al final sin recorrerbotones atrás/adelante, lista de canciones con «anterior», editores de texto, std::list
Circulardespués del último viene otra vez el primero, sin caso especialturnos que rotan (jugadores, procesos del sistema operativo), reproducir en bucle

El precio de la doble: una flecha más por nodo (más memoria) y el doble de flechas que mantener bien en cada operación. Si no necesitas ir hacia atrás, la simple basta.

¿Qué pasa en la memoria?

El nodo doble es el simple con una casilla más, y eso se paga en cada nodo del montón (heap). Compruébalo con cout << sizeof(Nodo);: en un ordenador de 64 bits normalmente da esto (el int ocupa 4 bytes, cada apuntador 8, y el compilador mete 4 de relleno para alinear):

Nodo simple
dato · siguiente
sizeof: normalmente 16
Nodo doble
dato · anterior · siguiente
sizeof: normalmente 24

Con un millón de nodos, unos 8 MB más. El objeto ListaDoble, en la memoria automática (la pila de llamadas o stack) si lo declaras en main, guarda dos apuntadores: cabeza y ultimo.

La circular no tiene nullptr que marque el final, y eso afecta al liberar. El destructor de la lección 3.2 borraría el 10, el 20 y el 30, y luego seguiría la flecha del 30… hasta el 10, ya liberado: leerlo y borrarlo otra vez es una doble liberación. Por eso primero se rompe el círculo. En la doble, antes de cada delete hay que redirigir las dos flechas que llegan al nodo; la que olvides queda colgante.
